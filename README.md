# PII Masker (PDF + Excel)

Веб-сервис: пользователь входит, загружает PDF или Excel, сервис возвращает обезличенный файл. Персональные данные заменяются похожими ненастоящими значениями, поэтому текст остаётся осмысленным, но не содержит настоящих данных.

## Запуск

1. Установить зависимости: `setup.bat`
2. Запустить LM Studio, загрузить модель и включить локальный сервер (по умолчанию `http://127.0.0.1:1234/v1`). LLM необязательна: структурированные ПДн находятся регулярками и без неё.
3. Запустить `python main.py` (или `.venv\Scripts\python.exe main.py`).
4. Откроется `http://127.0.0.1:9321`. Для доступа с других ПК — `http://<IP-компьютера>:9321`.

Учётка по умолчанию: `admin / admin` (файл `data/users.json`).

## Настройки (`settings.json` рядом с main.py/exe)

```json
{
  "lm_studio_url": "http://127.0.0.1:1234/v1",
  "model": "google/gemma-4-e2b",
  "api_key": "lm-studio",
  "temperature": 0.0,
  "max_tokens": 1024,
  "request_timeout": 90,
  "max_llm_chars": 12000,
  "host": "0.0.0.0",
  "port": 9321,
  "open_browser": true
}
```

`host: 0.0.0.0` открывает доступ по IP. Для доступа только с этого ПК: `127.0.0.1`.

## Что заменяется

- ФИО — фейковое ФИО (с подмешиванием случайных букв).
- Телефоны, email, адреса, организации — фейковые значения того же формата.
- ИНН, КПП, ОГРН/ОГРНИП, СНИЛС, паспорт, счета (20 цифр), БИК — другие числа/номера с сохранением формата.
- Суммы, количества и прочие числа — другие числа той же длины, с теми же разделителями.
- Даты — сдвиг на случайное количество дней.

Одинаковые исходные значения в пределах одного документа заменяются одинаково (кэш фейков).

- PDF: исходный текст вырезается через redaction, поверх него рисуется фейковый текст шрифтом Arial. Обрабатываются целые текстовые фрагменты (span), поэтому метки вроде `ИНН`, `КПП`, `ОГРН` не сдвигаются и не перекрываются. Страницы и структура сохраняются.
- Excel: строковые ячейки обрабатываются тем же маскировщиком, числовые ячейки получают фейковые числа, даты сдвигаются. Книга и форматирование сохраняются.
- Структурированные данные ищутся регулярками (работает даже без LLM).
- LLM (LangChain + LM Studio) дополнительно ищет неструктурированные ФИО, организации и адреса; если LM Studio недоступен, обработка продолжается без неё.

## RAG

RAG на LangChain (`InMemoryVectorStore` + локальные hash-эмбеддинги, без внешних вызовов). Правила лежат в `main.py` и могут дополняться файлами `data/knowledge/*.txt`. RAG используется только как контекст для необязательного поиска дополнительных ПДн через LLM. AI-помощника, чата и инструментов в интерфейсе нет.

## Сборка exe

`build.bat` → `dist\PIIMasker.exe`. Рядом с exe создаются `settings.json` и `data/`. При запуске сайт открывается автоматически.

## Ограничения

- Поддерживаются PDF с текстовым слоем и Excel `.xlsx` (не `.xls`). Сканы без OCR не обрабатываются.
- PDF с паролем не поддерживаются.
- История обработки не хранится; готовые файлы лежат в `data/outputs`.
