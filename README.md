# PII Masker (PDF + Excel)

Веб-сервис: пользователь входит, загружает PDF или Excel, локальная LLM в LM Studio находит ПДн, сервис возвращает обезличенный файл (все значения заменены на `***`).

## Запуск

1. Установить зависимости: `setup.bat`
2. Запустить LM Studio, загрузить модель и включить локальный сервер (по умолчанию `http://127.0.0.1:1234/v1`).
3. Запустить `python main.py` (или `.venv\Scripts\python.exe main.py`).
4. Откроется `http://127.0.0.1:9321`. Для доступа с других ПК — `http://<IP-компьютера>:9321`.

Учётка по умолчанию: `admin / admin` (файл `data/users.json`).

## Настройки (`settings.json` рядом с main.py/exe)

```json
{
  "lm_studio_url": "http://127.0.0.1:1234/v1",
  "model": "google/gemma-4-e2b",
  "api_key": "lm-studio",
  "temperature": 0.0,
  "max_tokens": 1024,
  "request_timeout": 90,
  "max_llm_chars": 12000,
  "host": "0.0.0.0",
  "port": 9321,
  "open_browser": true
}
```

`host: 0.0.0.0` открывает доступ по IP. Для доступа только с этого ПК: `127.0.0.1`.

## Что маскируется

ИНН, КПП, ОГРН/ОГРНИП, СНИЛС, паспорт, телефоны, email, ФИО, организации, адреса, счета (20 цифр), БИК.

- PDF: текст вырезается через redaction и заменяется на `***`, страницы/расположение сохраняются.
- Excel: значения ячеек заменяются, книга сохраняется.
- Структурированные данные ищутся регулярками (работает даже без LLM).
- LLM (LangChain + LM Studio) дополнительно ищет ФИО, организации и адреса; если LM Studio недоступен, обработка продолжается без неё.

## RAG и инструменты

RAG на LangChain (`InMemoryVectorStore` + локальные hash-эмбеддинги, без внешних вызовов). Правила лежат в `main.py` и могут дополняться файлами `data/knowledge/*.txt`.

Инструменты LangChain: `search_rules`, `detect_pii`, `mask_text_tool`, `extract_pdf_text_tool`, `extract_excel_text_tool`, `mask_pdf_tool`, `mask_excel_tool`. Они доступны агенту через `/api/chat` и перечислены в `/api/tools`.

## Сборка exe

`build.bat` → `dist\PIIMasker.exe`. Рядом с exe создаются `settings.json` и `data/`. При запуске сайт открывается автоматически.

## Ограничения

- Поддерживаются PDF с текстовым слоем и Excel `.xlsx` (не `.xls`). Сканы без OCR не обрабатываются.
- PDF с паролем не поддерживаются.
- История обработки не хранится; готовые файлы лежат в `data/outputs`.
